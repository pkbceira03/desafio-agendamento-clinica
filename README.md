# desafio-agendamento-clinica
Desafio técnico para vaga de Estágio Full Stack: um mini sistema de agendamento inteligente com validação de disponibilidade, bloqueio de feriados (via API externa) e finais de semana. Construído em arquitetura de camadas utilizando Node.js, React, TypeScript, PostgreSQL, Docker e Vitest para testes automatizados.
